## 日常升级流程备忘

1. `git fetch origin --tags` 确认官方新 tag
2. `git checkout -b v0.2.X-sshzyu v0.2.5-sshzyu && git rebase --onto v0.2.X <旧merge-base> v0.2.X-sshzyu`
3. 改 `backend/cmd/server/VERSION` → `0.2.X-rN`
4. `go build ./...` + 定制区测试 → `docker build -t local/sub2api-batch:0.2.X-rN`
5. 本地 `SUB2API_TAG=0.2.X-rN docker compose -f deploy/docker-compose.dev.yml up -d sub2api` 验证
6. `docker save | gzip` → scp → `docker load` → 生产 compose 改 tag → `up -d`
