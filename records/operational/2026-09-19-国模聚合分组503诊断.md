## 一、最终结论

**根因：group 65 是「聚合分组」（platform=`composite`），网关会先按请求的模型名推断出一个「目标平台」，再只在该平台的账号池里选号。而 group 65 的账号池里没有任何 deepseek 平台账号。**

- 请求 `deepseek-v4-flash` → 推断平台 = **deepseek** → 该平台在 group 65 内的账号数 = **0** → 选号池空 → **503**
- 请求 `glm-5.3-flash` → 推断平台 = **zhipu** → 池内有账号 91 → **200 成功**

503 **不是**外部网络 / CDN / nginx 的问题，而是 sub2api 应用层的选号失败（错误体为应用 JSON：`{"error":{"message":"No available accounts: no available accounts","type":"api_error"}}`）。

「内部测试全通过」与「外部 503」**不矛盾**：后台账号列表的「测试」按钮只验证**账号凭据连通性**，不经过平台的推断与选号闸门。

## 三、机制（代码链）

### 1. 请求一进 handler 就被硬绑平台

`internal/handler/composite_platform.go:13-23`

```go
func ensureCompositeTargetPlatform(c *gin.Context, apiKey *service.APIKey, model string) {
    if apiKey == nil || apiKey.Group == nil || apiKey.Group.Platform != service.PlatformComposite { return }
    if _, ok := service.ResolvedTargetPlatformFromContext(c.Request.Context()); ok { return }
    if platform, ok := service.DetectModelPlatform(model); ok {
        c.Request = c.Request.WithContext(service.WithResolvedTargetPlatform(c.Request.Context(), platform))
    }
}
```

`DetectModelPlatform`（`internal/service/composite_platform.go:151`）含规则 `strings.HasPrefix(normalized, "deepseek-") → PlatformDeepseek`。

### 2. 平台解析优先级：context 硬绑 > 显式路由表 > 账号归属(ownership) > 内置探测器

- `internal/service/gateway_scheduling.go:973-980`：`resolvePlatform` **第一优先**读 context 里已解析的平台，命中即返回。
- `internal/service/composite_platform.go:176-193`：`resolveCompositeRouteDecision` 一旦发现 context 已有平台，**直接返回，不再查路由表或 ownership**。

**推论（重要）：只要模型名能被 `DetectModelPlatform` 识别（`deepseek-*` 就能），那么**
- 修改 91 的账号声明（ownership）**无效**
- 配置 `composite_model_routes` 显式路由**同样无效**（会被硬绑抢先跳过）

### 3. 选号池按「分组 × 平台」分桶

`internal/service/scheduler_snapshot_service.go:210-213`

```go
useMixed := (platform == PlatformAnthropic || platform == PlatformGemini) && !hasForcePlatform
mode    := s.resolveMode(platform, hasForcePlatform)
bucket  := s.bucketFor(groupID, platform, mode)   // ← 桶 = (group 65, "deepseek")
```

`deepseek-v4-flash` 落进 `(65, deepseek)` 桶；group 65 内无 deepseek 平台账号 → 空桶 → `ErrNoAvailableAccounts` → 503。
