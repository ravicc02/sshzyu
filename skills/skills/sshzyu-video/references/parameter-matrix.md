# SSHZYU 视频参数矩阵

来源：`https://sshzyu.com/docs/vedio/content.md`，并核对测试 Key 的 `GET /v1/models`，日期为 2026-11-15。

模型和价格会变化。执行前先用 `models --kind video` 核对当前 Key 分组。下表不替代实时模型列表和服务端校验。

实测同一测试 Key 的 `/models` 可能在连续请求中返回不同账号集合。脚本因此只把模型可见性作为警告，不因单次列表缺失而自动换模型或阻断提交。

## 字段校验

脚本在提交前检查：

- `model` 非空且没有空白或控制字符。
- `prompt` 非空，最多 32000 字符。
- `seconds` 为 1～60 的整数。
- `resolution` 为 `480p`、`720p`、`768p`、`1080p`、`2k`、`4k`、`auto` 或 `adaptive`。
- `aspect_ratio` 在站内常用画幅列表中。
- 参考 URL 使用公网 HTTPS。
- 扁平 URL 数组与 `references` 不混用。
- 参考图片最多 30、视频最多 10、音频最多 10。

脚本做的是通用客户端校验。模型单独限制仍以 SSHZYU 文档和实际响应为准。

## 计费风险提示

脚本只展示生成秒数、分辨率、模型和任务数，不自行推算最终金额。原因如下：

- 按秒模型的单价随分辨率变化。
- 按次模型与实际秒数无关。
- 按 Token 模型需要任务完成后的 `usage.total_tokens`。
- 超时或上游失败可能已经产生请求或部分处理费用。

`--dry-run` 不读取 Key、不联网、不计费。
