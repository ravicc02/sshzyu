**总结**：

  1. `location = /image` → 301 `/image-playground/`（旧链接不断）

  3. 新增 `location = /image-playground` → 301 `/image-playground/`（规范化尾斜杠，PWA 相对路径资源必需）

### Q4：当前ui在本地启动但没有生效，为何？

**日期**：2026-09-29
**总结**：
- 本地启动有两种方式，可能混用导致问题：
  - **开发模式**：`cd frontend && pnpm dev` → Vite 开发服务器（默认端口 3000），反代 `/api`、`/v1` 到后端
  - **本地站点模式**：`sshzyu-local-site/docker-compose.yml` 启动 nginx 容器 `sshzyu-ui-local`（端口 127.0.0.1:8080）
- 没生效的常见原因（按概率）：
  1. 后端容器 `sub2api-dev` 没启动或未 healthy（应先 `curl http://127.0.0.1:8081/health` 验证）
  2. `VITE_DEV_PROXY_TARGET` 环境变量指向的后端地址不对
  3. 端口 3000 或 8080 被其他进程占用
  4. 前端依赖未装（`pnpm install`）
  5. 浏览器缓存旧版本（清缓存或无痕模式重试）
- 推荐的排查顺序：后端健康 → 端口占用 → 代理配置 → 浏览器缓存
**来源/依据**：AGENTS.md 第 6 节（本地开发拓扑）；`frontend/vite.config.ts` 服务器配置

### Q10：用户批注纠正——Q8 方案方向错误，最终定论恢复原始结构

**问题**：用户批注指出 Q8 的 nginx 方案（PWA 挂 `/image-playground/`）不是他想要的效果。实际症状：① key 选择不了；② 点「新窗口」打开的是 `/image-playground/` 而非 `/image`；③ 在工作台进入工作室后刷新，直接落到全屏 PWA（新窗口状态），不保留在嵌套工作台；④ 期望：恢复原样——PWA 挂 `/image/`，面板「生图工作室」= Vue 内嵌页（iframe 嵌 `/image/?token` → 有 key 选择），点「新窗口」打开的就是 `/image`。
**总结**：
- **Q8 方案的两个实质缺陷（比「丢参数」更根本）**：
  1. **路径冲突破坏了 Vue SPA 路由刷新**：面板菜单「生图工作室」本身是 Vue 路由 `/image-playground`（无尾斜杠）。刷新时浏览器请求该路径，Q8 加的 `location = /image-playground { return 301 /image-playground/... }` 把它 301 到纯 PWA → 整页变成全屏工作台、侧边栏消失（症状③）。而原始配置里该路径**没有任何 location**，落到 SPA fallback，由 Vue 路由器渲染内嵌页——刷新自然保留。
  2. **「新窗口」按钮 open 的是 iframe 地址**：恢复原始结构后其目标即 `/image/?user_id&token`（直达 200，不再经 301），地址栏就是 `/image`（症状②④）。
- **结论**：这轮折腾的唯一正确形态就是**原始配置**——`/image` 是 PWA 唯一 nginx 入口，`/image-playground` 交给 SPA fallback。iframe `/image/?token` 200 直达、不经跳转，token 天然不丢（症状①随之消失）。
- **已执行恢复**：用改动前备份 `/root/sub2api.bak-20260929-v2` 覆盖 `/etc/nginx/sites-enabled/sub2api`（当前版本另存 v3 备份），`nginx -t` 通过 + reload。实测：`/image/?user_id=1&token=TESTTOKEN` → **200 直达 ImagePlayground**（无 301）；`/image` → 301 `/image/`；`/image-playground` → 200 SSHZYU SPA 壳；sw.js / manifest 200。
- **教训沉淀**：给 Vue history 路由的路径加 nginx 规则前，必须先确认它是否与 SPA 前端路由撞名——SPA 路由依赖「无 location 命中 → fallback 到 index.html」，任何针对该路径的 301/alias 都会破坏刷新。另外 PWA/浏览器缓存（SW scope 变更残留）会放大排障噪音，验证一律以 curl 无缓存实测为准。
