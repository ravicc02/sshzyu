# Gemini 批量生图配置流程适配

日期：2026-10-02

状态：代码已实施，本地构建与非计费流程验证通过；真实上游生成待费用授权。

## 目标与边界

- OpenAI 与 Gemini 共用“需求转换 → 配置卡片 → 参数分组提交 → 总任务详情”的用户流程。
- 不修改 Gemini / Vertex provider、调度、计费或批量接口协议。
- 只改前端源码、相关测试和内部计划文档；不操作线上服务，不执行数据库迁移。

## 实施内容

- 转换器根据 Key 的平台选择既有尺寸与比例矩阵，继续使用英文 `;` 和 `,` 分隔输入。
- 模型来自原 `/v1/images/batches/models`，自动模型在提交前解析为实际模型。
- Gemini 卡片按模型校验尺寸、输出格式和参考图数量，与现有后端参考图限制保持一致。
- 统一参考图和逐项参考图均支持 Gemini 多文件选择、拖放、预览和逐张移除；OpenAI 保持原单参考图交互。
- 多参数组继续提交原批量接口，共用 `collection_id` 汇总展示。
- 两平台共用持久化幂等键、部分提交恢复和断网恢复；浏览器只保存参考图元数据，恢复时要求重新上传原附件，不静默降级为文生图。
- 平台切换确认清空平台相关草稿；同平台 Key 切换重新校验模型能力，保留原草稿供用户修正。

## 验收

- 单元测试：两平台矩阵、Gemini 模型能力、参考图数量、附件展开上限。
- 组件测试：Gemini 转换提交、多图上传与移除、统一参考图切换、平台切换、断网恢复、并发幂等、附件不持久化。
- 静态验证：TypeScript、定向 ESLint、前端构建。
- 本地浏览器：桌面和移动布局、真实 Key 模型加载、配置编辑及可用上游用户流程。
- 若本地无合规 Gemini 上游或 Key，记录实际阻碍；不擅自修改分组或凭证配置，也不把模拟验证描述为真实上游通过。
