# AI 漫剧与短剧工作流

适用：AI 视频、AI 漫剧、AI 真人感短剧，以及 AI 与实拍混合的微短剧。

本文件描述**旧版镜头清单（manifest）流程**，对应 `scripts/sshzyu_media.py drama run|assemble`。它不是短剧阶段化创作流程（后者见 `$short-drama-*`），也不是 `short-drama-produce` 的生产任务单 adapter。新项目请优先使用阶段技能与生产任务单。

## 总体流程

```text
立项
  -> 剧本与分集
  -> 视觉圣经
  -> 分镜和镜头清单
  -> 60 秒至 120 秒试片
  -> 批量生成
  -> 配音、拟音、环境声、音乐
  -> 剪辑、字幕、包装
  -> QC、AI 标识、版权
  -> 交付和多平台版本
```

不要跳过试片。试片至少覆盖：

- 主角近景。
- 两个角色同框对话。
- 一个连续动作。
- 一个新场景。
- 一个需要口型的镜头。
- 一个由生成视频、配音和剪辑共同完成的段落。

## 内容路线

| 类型 | 主路线 | 关键风险 |
| --- | --- | --- |
| AI 视频 | 图生视频、文生视频、关键帧 | 动作不可控、主体漂移 |
| AI 漫剧 | 静态资产、2.5D 分层、有限动画 | 画风不统一、口型不自然 |
| AI 真人感短剧 | 图生视频、Avatar、实拍混合 | 人脸不一致、连续表演不足 |

真人近景对白优先考虑实拍、许可 Avatar 或稳定的图生视频加口型。中远景、空镜、危险场景和特效更适合纯生成。

## 镜头设计

推荐单镜头 2 秒至 6 秒，一个镜头只承担一个主要动作。

不要在一个 prompt 中同时要求：

- 走路。
- 转身。
- 说话。
- 拿手机。
- 镜头环绕。
- 多人互动。

应拆成正反打、动作、反应和插入镜头，在剪辑中形成连续动作。

分镜最小字段：

| 字段 | 说明 |
| --- | --- |
| `id` | 唯一镜头号，例如 `EP01_SC03_SH04` |
| `prompt` 或 `prompt_file` | 单一动作描述 |
| `model` | 精确模型名 |
| `seconds` | 生成秒数 |
| `resolution` | 输出分辨率档位 |
| `aspect_ratio` | 输出画幅 |
| `image_urls` | 公网参考图片 |
| `video_urls` | 动作或镜头参考视频 |
| `references` | 首尾帧或角色参考 |

## 视觉一致性

批量生成前锁定：

- 角色正面、侧面、背面。
- 三种以上表情。
- 两套以上服装。
- 场景主视角和反打视角。
- 色彩、光线和镜头语言。
- 字体、字幕、片头和片尾。

一致性控制不要只依赖提示词。组合使用：

- 固定角色参考图。
- 固定模型和版本。
- LoRA、ControlNet、深度或姿态控制。
- 首帧、尾帧和关键帧。
- 固定 prompt 模板。
- 每镜头保存 seed、模型、参数和素材哈希。

## Manifest

```json
{
  "project": "demo-drama",
  "defaults": {
    "model": "minimax_h3",
    "seconds": 4,
    "resolution": "480p",
    "aspect_ratio": "9:16",
    "poll_interval": 5,
    "poll_timeout": 1800
  },
  "shots": [
    {
      "id": "EP01_SH001",
      "prompt": "雨夜街头，女主回头，镜头缓慢推近"
    },
    {
      "id": "EP01_SH002",
      "prompt_file": "prompts/EP01_SH002.txt",
      "seconds": 5
    }
  ],
  "assembly": {
    "resolution": "1080x1920",
    "fps": 25,
    "audio": "audio/voice.wav"
  }
}
```

相对路径以 manifest 所在目录为基准。

## 批量执行

```powershell
py -3.12 -I -X utf8 "${SKILL_DIR}/scripts/sshzyu_media.py" drama run `
  "drama.json" --out "OUTPUT_DIR" --dry-run
```

确认后加 `--confirm`。

默认行为：

- 顺序执行。
- 每镜头创建一个独立视频任务。
- 第一镜头前核对模型权限。
- 失败默认停止后续镜头。
- 每个任务只创建一次。
- 已取得 task id 后查询失败，不重新创建。

续跑：

```powershell
py -3.12 -I -X utf8 "${SKILL_DIR}/scripts/sshzyu_media.py" drama run `
  "drama.json" --resume-run "EXISTING_RUN_DIR" --confirm
```

只有状态为 `success` 或 `partial` 且视频文件仍存在的镜头会被跳过。

## 成片装配

```powershell
py -3.12 -I -X utf8 "${SKILL_DIR}/scripts/sshzyu_media.py" drama assemble `
  "RUN_DIR" --out "final.mp4"
```

装配逻辑：

1. 按 manifest 镜头顺序读取成功任务。
2. 统一缩放、补边、SAR 和帧率。
3. 使用 FFmpeg concat filter 重新编码，避免不同源的时基问题。
4. 默认移除镜头原声。
5. 可附加外部配音轨并补齐到视频总时长。
6. 输出 H.264、AAC、`yuv420p` 和 `faststart` MP4。
7. 用 FFprobe 校验分辨率、时长和流。

正式项目仍应在非编软件中完成精剪、字幕、音乐、混音和平台包装。

## 声音顺序

1. 角色试音和音色锁定。
2. 对白录制或 TTS。
3. 对白修剪和降噪。
4. 视频表演、口型或 Avatar。
5. 拟音、环境声和音乐。
6. 终混。
7. 字幕按终混逐句校准。

声音克隆和肖像生成必须取得表演者及权利人的明确授权。

## QC

单镜头检查：

- 身份：脸、发型、肤色、年龄感和身体比例。
- 服装：颜色、材质和图案。
- 动作：手指、关节、重心、脚底滑动。
- 表演：视线、口型、呼吸和情绪。
- 场景：背景、道具、光源和天气。
- 画质：闪烁、糊化、融化、压缩块和文字伪影。
- 声音：爆音、底噪、断句和音画同步。

成片检查：

- 画面和声音连续。
- 字幕与终混一致。
- 黑帧、静帧、重复帧和音画不同步。
- 平台压缩后的文字和细线。
- AI 显式标识、隐式元数据和平台声明。
- 版权、字体、音乐、肖像和声音授权。

## 中国大陆合规

《微短剧发展管理办法》自 2026-09-01 起施行。使用 AI 生成、制作的微短剧，应在每集明显位置添加提示标识。

同时遵守《人工智能生成合成内容标识办法》的显式标识和隐式标识要求。

制作前确认：

- 一类、二类或三类微短剧分类。
- 是否需要备案公示、内容审核、发行许可证或节目编号。
- 片头应标注的许可证号、批准文件编号或节目编号。
- 目标平台是否接受当前成片版本。

不得未经授权：

- 复刻演员、网红或公众人物脸部。
- 克隆配音演员、歌手或普通人的声音。
- 使用受版权保护的角色、影视片段或音乐。
- 删除、伪造、篡改或隐匿 AI 标识。

具体许可和备案要求应由制片机构向属地广电主管部门及发行平台复核。本文件不构成法律意见。
